ARQUITETURA ANDROID 100% LOCAL

VÍDEO MATERIAL IA PARA ANDROID

Três formas reais de rodar no seu smartphone ou tablet Android sem depender de servidores pagos ou créditos.

1. Instalação Direta (PWA / WebAPK)

Funciona imediatamente no Chrome do Android em tela cheia offline. Usa `MediaRecorder H.264/MP4`, câmera nativa, `TextToSpeech` local e WebGL 2.0.

Requisitos: Android 8.0+ • 2 GB RAM

2. Projeto Nativo Android Studio (.APK)

Código-fonte completo em **Kotlin** (`MainActivity.kt` + `AndroidBridge` + `FFmpegKit` + `ONNX Runtime Mobile` + `Android TTS`) incluso no pacote `.ZIP`.

Gera APK via Gradle / GitHub Actions

3. Motor Python + FFmpeg no Termux

Execute o `local_video_engine.py` diretamente dentro do Android usando o app gratuito **Termux** com FFmpeg nativo ARM64.

pkg install ffmpeg python opencv
